# 《紙妻》免 Token V6.10｜角色視角、歷史劇本與證據對質修正版

此 ZIP 可直接部署到 GitHub Pages。**V7.0 AI 模式暫不納入**；完全不需要 Groq 金鑰或 Cloudflare Worker。

## V6.10 修正內容

1. **問句視角全面檢查**：玩家扮演戴思齊時，不會問「你看見戴醫生或紅豆嗎？」；改為符合當事人第一人稱的自然提問。陳聿明、孟小婉等角色相關稱謂同樣處理。新版會在所有腳本覆寫完成後、問題顯示前再次處理稱謂，避免深度問答或次級追問把舊問題重新帶回畫面。
2. **右上角「歷史劇本」**：可隨時回看自己角色從第一幕到**目前已到達幕次**的全部私人劇本；不展示其他角色的私人內容或之後尚未到達的幕次。每次開啟自動回到最上方；第一次閱讀新幕時則只顯示該幕內容。
3. **其他角色搜證後自動開啟公開情報**：點選「其他角色搜證」後，右側調查手冊自動打開，先列出本輪新公開的卡片，提供「我已讀完，返回遊戲」，下方仍可回看歷次已公開卡片。沒有公開的 NPC 私人卡不會被顯示。
4. **阿忠拒絕自爆**：根據原始角色劇本，阿忠被要求隱瞞自己殺害惠雯並設法轉移嫌疑。第四幕不再讓他直接承認最後致命勒頸；取而代之的是他的推託、出入時間空白、麻繩來源與「誰最後見到惠雯仍活著」的證詞矛盾。
5. **第四幕有真實推理路徑**：紅豆約 22:50 接近惠雯，昏迷到約 23:25，無法證明最終致死；阿忠則迴避某段出入婚房時間、承認與惠雯爭執，並利用其他人有機會接觸現場來辯解。玩家可結合已獲得的勒痕、迷藥、房間行蹤與公開對話核對。這些問題**不等於公布答案**，選錯對象、忽略時間仍可能推錯。
6. **保留原本完整內容**：V6.9 的第二至第四幕公開盤問（每人兩名不同對象，總共 12 組）、玩家兩名對象的三層問答、四幕、抽卡、圖片、公開情報、結局與存檔機制均繼承。

## GitHub Pages 更新方式

下載並解壓 ZIP，**上傳 ZIP 內全部內容到 Repository 根目錄**，確認 `index.html` 直接位於最外層，並同時上傳新增的 `data/role-context-and-evidence.js`。

GitHub Pages 保持 `main` / `/(root)`；部署完成後按 `Ctrl+F5` 強制重新整理。既有存檔沿用原本鍵值，但若舊存檔停留在已調整過的早期幕次，建議在遊戲裡重新開始以測試完整流程。

## 測試與限制

- 已檢查七位玩家視角、第二至第四幕、每位可問對象全部分支的 4,914 個玩家／角色／幕次／問答節點組合；修正後沒有玩家以自己的姓名、醫生或老爺稱謂把自己當第三人稱的問題。
- 已透過本地 Chromium 在注入式頁面測試 JavaScript 載入、戴思齊詢問阿忠、跨幕歷史劇本、其他角色搜證自動開啟公開情報，以及第四幕阿忠的防守式問答。測試**不是**在使用者的線上 GitHub Pages 完整遊玩。
- 這版針對已發現的角色視角錯誤與兇手自爆做修正，但不聲稱每個隨機抽卡組合都能取得所有關鍵物證；仍應透過證詞時間線交叉推敲。不能把缺乏已公開證據的內容當作已被證實的事實。
- 免 Token 版本是純前端網站，玩家若刻意查看原始碼可讀到預設劇情資料，請依正常遊戲介面逐幕閱讀以避免劇透。
