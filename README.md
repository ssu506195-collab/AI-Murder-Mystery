# 紙妻 V6.7 — 免 Token GitHub Pages 完整版

這一版以六格 UI 參考圖作為版面重建基準，保留 V6.6 的四幕劇本、固定問答、線索抽取、公開問答、投票與瀏覽器存檔。

## 網站畫面
- 首頁：群像滿版背景＋左側「劇本殺」標題、劇情玩法簡介及兩個主要操作鍵
- 劇本選擇：置中標題＋單一大幅橫向《紙妻》劇本卡（可再新增劇本）
- 選角：七張橫向排列的人物卡，自由選角或隨機分配
- 在場人物介紹：全螢幕中式宅邸背景、左側人物去背立繪、右側公開介紹卡、卡內下一位
- 序章：單張背景與底部金邊文字框，逐字顯示，按一下可顯示全文，再按下一段
- 問答：左右人物立繪、中央問題選項、下方答覆框；玩家選問句後自動接答覆，角色答覆結束後手動前進

## 部署 GitHub Pages
1. **只解壓縮 ZIP 內的檔案**，放進 GitHub Repository 根目錄，包含 `index.html`、`app.js`、`style.css`、`reference-ui.css`、`data/`、`assets/`、`.nojekyll` 等。
2. 於 GitHub Repository `Settings → Pages` 設定從 `main` 分支 `/(root)` 發布。
3. 重新整理網頁（Windows：`Ctrl + F5`）。
4. 若要看完整 V6.7 開場流程，請按「重新開始」，因為前版的 `localStorage` 存檔仍會保留。

## 測試
- JavaScript 語法與 9 張角色立繪、3 張場景圖本地資產路徑檢查
- Chromium 1536×900：首頁、選劇本、選角、七位角色介紹、序章、第一幕閱讀、神婆儀式、第一位角色三層問答
- 公開情報側邊抽屜開啟

## 限制
這是靜態純免 Token 版：玩家在正常遊戲流程中只會看到已解鎖內容，但直接查看原始碼仍可能取得完整劇本資料。這版沒有修改 Token 模式，也沒有重新撰寫全部角色問答。

不同螢幕大小會使用響應式排版，故不可能每個設備都和 1536×900 的設計稿像素完全相同。此版採用已生成的中式陳宅場景與角色素材，不是把參考六格圖直接做成不可互動的背景圖。


## V6.8a 深度問答版
- 保留 V6.8 完整遊戲流程、四幕、角色立繪、雙欄抽卡與存檔。
- 依角色當幕資訊重寫 **84 組主問答**與 **252 組第一層追問回答**，每個分支有不同的具體證詞；其餘 756 個第二層追問維持既有問題及回答。
- 逐幕改寫 **12 段 NPC 與 NPC 公開質詢**（每段有兩次提問與兩次具體回覆）。
