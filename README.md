# 《紙妻》免 Token V6.13｜固定搜證與證據鏈修正版

本壓縮檔為完整靜態網站。將 ZIP **內的檔案與資料夾**放到原本 GitHub Pages Repository 根目錄（`index.html` 位於根目錄），覆蓋原有版本即可；本版不包含、也不會啟用 V7 AI 功能。

## 本版重要變更

1. **固定分卡，仍保留「抽取」的遊戲儀式感**：七個角色各自有指定提示卡；每局第一輪共 21 張、第二輪 35 張、密室 14 張，沒有重複。玩家選不同角色會改變自己的手牌，但固定配置不因重開遊戲而改變。公共卡照既有規則公開，NPC 私人卡僅部分按指定順序公開；剩下的仍是角色私人資訊。
2. **問答資訊來源檢查**：玩家問題不能在尚未取得證據前假定精確的時刻；無來源的時間斷言改為先詢問行蹤和目擊。玩家主問題（第二到第四幕，7 名受訪者，每幕 3 問，共 63 問）改成有具體事件依據的盤問。
3. **NPC 公開盤問重寫**：第二至第四幕各 12 組，總共 36 組依玩家角色安排的討論場次；每個場次的問題、回答、第二次追問都有對照角色經歷。討論在玩家詢問前進行，角色間仍輪流分擔發問與被問。注意每幕的 12 組公開對話會隨玩家的角色由對應人物出演，並非 36 場完全不同的劇情。
4. **新增來源限定的物證對質**：根據確實持有或已公開的卡片，追加玻璃／背傷、勒痕與麻繩、未喝的水、注射器、昏迷枕頭、屍檢死亡時間等對質；每幕最多四次，已解鎖的對質可留到後幕完成。對方會依劇本迴避、承認有限事實或要求核對，不會直接自白致命殺人行為。
5. **推理筆記**：重要對質留下尚待查證的矛盾摘要，不直接把嫌疑人當作兇手公布。
6. 保留 V6.12：七人角色視角的稱謂修正、21 條交叉查證、劇本回看、四幕、卡片正文清理、圖片與場景。

## 遊戲與公平性說明

固定抽卡不代表一開始揭露全部私密資料；需要結合公開詢問、主問、追問和物證對質，才能逐步分辨證詞矛盾。阿忠玩家本來就知道自己的秘密；其目標不是推理自己的犯行，而是隱瞞與應對他人的查證。其他六人不會從旁白直接得到真兇姓名。

固定線索和新問答已做程式結構與七種玩家配置的本地模擬檢查。**這不等於已對七種玩家身份的所有問答選擇進行真人盲測**；仍可能有未察覺的推理難度或故事詮釋問題。為避免舊版隨機抽卡存檔造成錯配，本版使用新的儲存 key，請從首頁重新開始遊戲。

本版本為純前端免 Token 網站；玩家一般介面只顯示當幕開放的內容，但技術上可以在瀏覽器開發工具中讀取打包的資料，並不具備伺服器等級的私密劇本隔離。遊玩時應遵守只閱讀所選角色內容的規則。
