# 《紙妻》免 Token V6.14｜四幕時間線、物證與推理補強版

此壓縮檔是可直接部署至 GitHub Pages 的**完整靜態網站**。將 ZIP 內的 `index.html`、`app.js`、`style.css`、`reference-ui.css`、`data/`、`assets/` 與其他檔案全部上傳到 Repository **根目錄**即可。不必安裝套件，不需要輸入 API 金鑰；**本版沒有啟用 V7 AI 功能**。

## V6.14 的主要調整

1. **修正事件先後順序**：原本在第一輪提前出現的涼亭儀式殘跡、孔神婆頭顱（卡 33、34），移到第三幕密室事件後的第二輪搜證；第一輪改由原第二輪的卡 19、37 補足。固定發卡總量不變，七角色、所有卡片仍無重複。
2. **統一明確的原稿矛盾**：江靜儀對惠雯施針的位置採原始組織手冊的「右臂」，與原提示卡的手臂針孔一致；阿忠背景中宿主死亡後的病毒有效時間採手冊與《陳氏古法》卡片的「兩個時辰」。這是製作時的連續性校正，**不把劇情反轉或角色說謊改成無害真話**。
3. **九條新的可選推理查證**：以床底拖痕、昏迷後移動、玻璃碎片的有限比對、較早存活目擊、濕鞋與聲音、不同勒痕、記者的有限證詞、以及最後的多證據比較，形成循序調查。**每個結論都注明能證明什麼與不能證明什麼**。
4. **兩項現場與驗傷補充**：提示卡 87 新增床側至床底的拖擦痕與衣料纖維；提示卡 21 補充三道勒痕可能不同時、但不能單看深淺確認兇手。這是為了讓無 AI 版本能做公平推理而加入的**遊戲補充搜證觀察**，不是聲稱原始 Word 就有這兩句。
5. **防止上帝視角提問**：把原次級問答中「23:05 的致命勒痕」「23:25 被發現」等不合理的預設，改成詢問採樣先後、失去意識與目擊。正式發現遺體為 00:40，紅豆私下醒來的時刻不能無條件當成公共事實。
6. **角色不會向自己盤問**：玩家扮演紅豆、戴思齊或其他相關當事人時，改成「自行核對」已知劇本及實際得到的物證；自我推理只記入個人筆記，**不會寫進公開問答紀錄**。
7. **保留合理誤導**：管家對夜間去向的保留、醫師的器械疑點、記者可能有幻覺、園丁對傷口的模糊辯解，仍可能引導玩家錯判。這些誤導與問答的背景來源有關，不靠故意寫錯左右手或先後時間來製造難度。

## 遊戲規則與推理提示

- 第一輪 21 張、密室 14 張、第二輪 35 張，七角色固定分配，每局順序一致。
- 固定取得不代表全部公開：其他角色的私人卡仍只有部分被分享；主角只能依自己持有、他人已公開與親眼聽到的證詞提問。
- 仍維持**每幕最多四次物證對質**；額外可用的角色交叉查證依原有規則進行。本版**不額外縮減配額**，避免還未確認問題品質就強行提高難度。
- 進階物證比較必須完成對應的前置查證才會出現；只點到一張卡，不能直接取得完整結論。未必需要詢問所有角色。
- 玩家可以回看已解鎖私人劇本、公開情報與個人推理筆記，沒有解鎖的角色私人內容不會透過正常 UI 顯示。
- 兇手玩家有不同的扮演目標；不會在一般盤問選項裡直接認罪。

## 部署方式

1. 解壓本包，將根目錄全部內容上傳 GitHub Repository，覆蓋原版檔案。
2. 確認 `data/deduction-fixes-v614.js` 在 `data/` 目錄內，且 `index.html` 正確載入。
3. 等 GitHub Pages 更新後，按 `Ctrl + F5` 強制重新整理。
4. V6.14 使用新的瀏覽器儲存 key，請從首頁重新選角開始，以免舊版錯誤發卡與新版混在一起。
