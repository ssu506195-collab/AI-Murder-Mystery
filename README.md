# 紙妻｜免 Token V6.1 視覺更新版

本 ZIP 可以直接解壓縮後，把**內部檔案**上傳至 GitHub Pages Repository 根目錄。

## V6.1 調整項目

- 恢復完整大圖風格的首頁：首頁 → 選擇劇本（目前一部）→ 角色選擇。
- 七位角色加入獨立肖像；可以自行選角或隨機抽角。
- 替換原本幾何剪影為角色圖；雙人對話時發言角色亮起，其他角色變暗。
- 序章改成打字機效果，按一下先補完當前文字，再按一下看下一段。
- 延用 V6.0 四幕遊戲、問答樹、線索抽取、結局及瀏覽器紀錄；**不改寫原有問答內容**。
- 全站仍為繁體中文、完全免 Token、不需要 Cloudflare Worker。

## GitHub 更新方式

1. 下載 ZIP 並解壓縮。
2. 把 `index.html`、`app.js`、`style.css`、`.nojekyll`、`data/`、`assets/` 上傳至 Repository 根目錄，覆蓋相同路徑舊檔。
3. 在 GitHub Settings → Pages 確認 main / (root)。
4. 發布後使用強制重新整理 `Ctrl + F5`，避免瀏覽器抓到舊的 CSS。

## 資料與素材說明

圖片是新製作的 1930 年代風格七人群像插畫擷取的各角色肖像，並非原劇本授權人物設定畫；人物服裝與身分細節可在後續版本持續精修。原有完整 V6 劇情資料保持不變。

**隱私提醒**：本版是純靜態遊戲，所有角色資料、解謎內容都存在公開前端檔案中；遊戲介面有依幕解鎖，但無法防止刻意查看原始碼取得劇透。

## 測試重點

- 首頁有「選擇劇本」，劇本卡片中可進入角色頁面。
- 七個角色都會顯示圖片；自行選角與隨機抽角都可開始。
- 序章旁白逐字浮現；點擊時先顯示完整句子，再播放下一句。
- 閱讀第一幕劇本後可以選角色詢問；對話左、右都有立繪並依說話方亮暗切換。
- 原版筆記、公開問答、抽提示卡等流程仍可使用。
