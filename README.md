# 《紙妻》免 Token V6.17｜第三幕密室敘事與身分推理銜接修正版

此為完整 GitHub Pages 網站。把 `index.html`、`app.js`、`style.css`、`reference-ui.css`、`data/`、`assets/` 等全部上傳原儲存庫根目錄即可，不需要 Token、Worker 或後端服務。請**重新開始遊戲**，新固定發卡與舊 V6.16 存檔不相容。

## 本版已修正

- 第三幕密室原只有三句旁白，改為八段現場敘事：摸黑進入、死者再次活動、舊屍與新屍的不同、孔神婆附身時提到的三位姨太太及分類任務，從原始組織手冊還原適合網頁的純文字演出。
- 密室正確辨識出第四人後新增六段公共調查整理，強調舊三位姨太太與新近孔神婆殘骸屬不同事件；密室出入與通風道會影響不在場證明，但**不直接指認惠雯兇手或判定存屍者**。
- V6.16 固定線索竟未發放原始第 61 號黃埔軍校照片與第 59 號半塊魚形玉佩：新版兩張改入第三幕第二輪固定搜證，仍維持每人 5 張、共 35 張；非玩家持有時會於 NPC 固定分享中公開，玩家自己持有時可直接查看。第二輪 NPC 會額外固定分享東青房內保存工具（76）及紅豆身上半塊玉佩（66），供密室與身分推理引用；公開卡片數比 V6.16 增加 2 張。
- 第二輪結束後新增玩家私人逐句「身分證據核對」，此階段不把玩家未公開的私人卡自動變成公共證詞；在了解照片與大火後的人事變化之前，不再直接問玩家陌生的「駱午陽」是誰。
- 身分推理題目改成「現任陳老爺是否為大火前原主人？」四個選項皆針對同一問題，不再出現「阿忠其實是孔神婆」。答案是合理懷疑冒名，**真名、原主人去向以及惠雯命案必須分開查**。
- 第三幕公開問答中，若保存工具卡已公開，東青須回答其房間保存工具與密室藏屍手法的可核對關係；若由玩家私下持有未公開，則只詢問一般出入，不偷用玩家秘密。他仍可隱瞞私人犯罪。
- 主線三至四幕的既有物證對質、自由選兩名角色三層問答、固定搜證、推理筆記與人物劇本保持不變。

## 設計基礎與限制

遊戲劇本原始手冊明確指定：第三幕密室須從十四項物件辨認三位舊姨太太及孔神婆，密室之後進入第二輪搜證，再推理現任陳聿明的假身分。密室不是直接解惠雯命案的終局題；玩家需要回查婚房機關、夜間出入、傷痕與死亡時間。新增台詞是基於原始演出流程的文字化敘事，不是聲稱原版 Word 逐字已有這些新旁白。

**尚未做真人七角色盲測。** 靜態前端仍可能透過開發者工具讀取全部劇本，介面雖然按角色隱藏，並非伺服器層級隔離。
