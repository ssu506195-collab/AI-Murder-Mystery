# 《紙妻》免 Token V6.9｜劇情順序與證詞來源修正版

此壓縮檔是可直接上傳 GitHub Pages 的完整靜態網站。**沒有加入 V7.0 AI 模式，也不需要 Cloudflare Worker / API 金鑰。**

## V6.9 重要變更

1. 第一幕**只閱讀角色劇本並演出孔神婆沖喜儀式**，演出完成直接進第二幕；不再讓玩家在第一幕使用未公開的資訊盤問其他角色。
2. 第二幕：閱讀 → 第一輪搜證 → **電腦公開證詞交換** → 玩家詢問兩名角色（每名三層）→ 玩家被問 → 第三幕。
3. 第三幕：閱讀 → 密室劇場 → 密室搜證與推理 → 第二輪搜證 → 主人身分推理 → 電腦公開證詞交換 → 玩家詢問兩名角色 → 玩家被問 → 第四幕。
4. 第四幕：閱讀 → 電腦公開證詞交換 → 玩家詢問兩名角色 → 玩家被問 → 投票與結局。
5. 公開詢問在每幕安排六位非玩家角色，每人向兩個不同的非玩家角色提問；每人也被詢問兩次，合計 12 組，避免資訊全部集中在某一人。
6. 第二幕主問與第二層追問以已演出的情境與公開證詞重寫；不存在的「已經找到／已經驗出」會先改為合理的查證問題。部分其他幕次問句也增加證據來源檢查。
7. 第四幕的「阿忠最後致命勒頸」與「紅豆先前接觸後曾昏迷」有可追問的證詞路徑，幫助區分多次傷害、最後死因、事後取血與移屍。
8. 保留 V6.8d 的角色專屬問句、V6.8a 深度答覆、V6.8b 圖片／提示卡及 V6.8c 劇本流程文字修正。

## 部署

將 ZIP **內部檔案**（不是外層 ZIP）上傳到 `AI-Murder-Mystery` Repository 根目錄，確保 `index.html` 位於最上層，GitHub Pages 設定為 `main` / `/(root)`。部署後重新整理。

**請從「重新開始」測試新流程**。舊版存檔可能停留在第一幕詢問階段，無法自動對應到已修正的幕次順序。

## 當前限制

本版在第二至四幕增加了固定的單人公開討論階段，用來替代實體遊玩時玩家之間自行交流；這是互動網頁的改編，不是原手冊逐句台詞。第二幕的主題與第三層追問已大幅整理，但第三、四幕其他部分既有的次級追問仍有可繼續潤稿之處。隨機抽卡不保證單場所有私人關鍵證物都會公開，玩家需要從公開證詞與選擇的追問交叉查證。
