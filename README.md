# 《紙妻》V6.12｜角色視角、交叉查證與提示卡清理

本壓縮檔為 **免 Token 模式**完整網站，可直接更新原有 GitHub Pages。未修改 V7.0 AI 模式。請將 ZIP **內的檔案與資料夾**（不是外層 ZIP 本身）上傳到 Repository 根目錄，`index.html` 必須位於根目錄。

## 本次修改

1. **玩家身分視角**：針對七位角色、第二至第四幕完整三層問答樹做全路徑檢查；依玩家身分修正第三人稱自稱。補寫「紅豆與江靜儀 00:25 一起開門」等會讓玩家像失憶的問句。對應 NPC 回答在需要時也改成對玩家說「你」。
2. **交叉查證**：新增 21 條特定事件的可選追查，例如某人的房門沒人應、20:40 閣樓目擊、00:25 走廊目擊、19:55 火災談話、21:35 雜物間、22:20 大門聲響。當公開問答或玩家的對話實際出現相關內容，才會在問答操作區出現「交叉查證：向某角色確認」按鈕。交叉查證不佔本幕玩家兩名深入詢問對象的配額；內容會加入公開問答紀錄。
3. **角色隱瞞**：修正可能讓東青過早承認冒答老爺、紅豆過度透露婚房接觸過程，以及戴思齊在沒有相應公開證據時被直接當面指控凌晨精確採血時間等情形。阿忠仍依原劇本隱瞞真正的致命勒頸行為。
4. **卡片文字**：保留 87 張提示卡、各卡 ID、分配與抽卡機制；從玩家看到的正文去除原文件開頭 `(01)`、`（02）` 等內部編號，以及「可深入至深入線索五」等未在此版實作的編輯註記；已清理 70 張有標記的卡片。
5. **其餘功能**：保留 V6.11 的四幕、歷史劇本、NPC 公開詢問、角色三層問答、結局、角色圖片與場景。
