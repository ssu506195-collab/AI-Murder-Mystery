# 《紙妻》V6.11｜七角色時間線與有效問答重整版

此壓縮檔為完整免 Token GitHub Pages 網站。V7 AI 模式暫未納入。ZIP 解壓後將全部檔案上傳到 Repository 根目錄；`index.html` 必須位於根目錄。

## 改版內容

- 第二、三、四幕的七位人物，各自三個主問題，直接依據角色劇本中的具體事件、時間和物證撰寫。每個主問題有三個實際可核對的追問方向，仍保留三層三選項結構。
- 最後一層改為角色與幕次專屬的證詞核對問題，不再使用「如果出現相反證據你怎樣解釋」等萬用字句。某些同角色同幕的終層可選問題仍會在不同主問題分支間重用。
- 每個非玩家 NPC 每幕兩次公開詢問，每人被詢問兩次，優先先提供地點／時間／目擊供玩家接續追問。
- 公開線索不再任意串接一段無關回答。只有人工編寫、與提示卡號及相關角色匹配的特定卡片才會觸發線索質問；其餘維持符合人物已知資訊的公開詢問。
- 阿忠依劇本隱瞞自己的致命行為，不會在回答中直接認罪。其他角色亦有能查證的行蹤、私心與可能誤導的證詞。
- 原遊戲幕次、隨機抽卡、公開情報、歷史劇本、選角、圖片與結局功能保留。

## 限制

這是對既有 6.10 問答的實際資料改寫，但角色回應不能在未實測的情況下保證所有答法都完全自然或所有隨機抽卡組合都能單獨導出真兇。第三層有部分同角色／同幕重用的具體查證題，仍可繼續優化。請優先測試各角色第二幕起的時間線推理與第 65 張紅豆傷疤線索的問答。
