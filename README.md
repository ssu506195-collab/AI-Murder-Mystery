# 紙妻｜免 Token 完整遊玩版 V6.0

本 ZIP 是**可直接上傳 GitHub Pages 根目錄**的純靜態網站；不需要 Node.js、npm、Cloudflare Worker，也**不需要 Groq API Key**。

## 如何部署

1. 先在自己的電腦解壓 ZIP。
2. 打開解壓後的資料夾，將 **`index.html`、`app.js`、`style.css`、`data`、`assets`、`.nojekyll`** 直接放到 GitHub Repository **根目錄**。**不要額外再套一層資料夾。**
3. 如果你原本的 GitHub 上已經有舊版 `app.js`、`data`、`index.html` 等，請先刪除/覆蓋過時檔案，以免兩套版本混用。
4. `Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save`。
5. 網址一般為 `https://<你的帳號>.github.io/<你的Repository>/`。

建議在正式展示前先在無痕視窗打開新版網站，避免以前的瀏覽器快取或存檔造成混淆。

## 已包含的免 Token 遊戲內容

- 七個可選玩家角色：陳聿明、東青、阿忠、戴思齊、孟小婉、紅豆、江靜儀。
- 七份完整角色劇本（人物故事＋四幕），從使用者提供的 DOCX 轉為繁體中文；**畫面只開放當前幕次，不會一次顯示後幕**。
- 第一幕的孔神婆沖喜儀式、第三幕密室劇場，對話一次顯示一句，必須點擊後才推進。
- 每幕玩家可以選兩位不同角色進行固定問答，每位角色每幕 3 個專屬主問題，每個主問題 3 個第一層追問，每個追問又各有 3 個第二層追問。合計 84 個專屬主問題。
- 其他角色間的公開詢問，以及別人詢問玩家時的 3 個實際台詞選項；全部記入「公開問答」。
- 87 張來自「線索卡文字檔.docx」的完整文字提示卡；第一幕不發線索。第二幕第一輪搜證每人 3 張，第三幕密室每人 2 張，第三幕第二輪搜證每人 5 張。單人玩法中其他六名角色也會依規則抽取並公開線索。
- 密室身分推理與假陳聿明身分推理。
- 第四幕結尾投票、可查看原組織手冊的陣營結局及完整真相。
- 本地瀏覽器自動儲存進度、公開線索、問答和個人筆記，按右上角「重新開始」可清除。

## 已知限制（請讀）

1. **免 Token 的公開靜態站無法保密角色劇本**：為了不使用伺服器，全部角色內容、固定選項和真相資料都在 `data/game-data.js`，**任何能查看 GitHub Repository 或瀏覽器開發者工具的人都可能提前讀到**。遊戲介面只按幕次顯示，是防止正常遊玩時劇透，不是安全防護。若要嚴格保密，未來必須改用後端保存秘密資料。
2. **搜證分類是單人網頁化調整**：原始《線索卡文字檔.docx》沒有圖片上標示的「第一輪／第二輪」角標與區域屬性，這版依文字內容暫定分類，沒有宣稱完全還原實體卡片分類。劇情的關鍵搜證配額和先後順序則依組織手冊。
3. **人物對話為固定劇本**：主問題依角色/幕次編寫，追問圍繞該題的具體焦點展開；不是即時 AI，也不是使用者可自由輸入的對話。某些第二層追問仍使用相似的查證/時間順序措辭，若要更細緻的個別反應可以逐角色繼續潤稿。
4. **畫面中的兩側人物目前是佔位人形**：沿用既有的書房背景素材，未找到本次七位《紙妻》角色對應的正式完整立繪；因此沒有把舊案件人物肖像錯當成新角色。需要的原創人像與場景可以在後續版本另外製作。
5. **單人投票的局限**：結尾的毀掉/保留陣營由玩家自行選擇，不模擬另外六人真實投票；保留組織手冊原文的陣營敘述以及完整復盤可查閱。
6. **繁體轉換**：劇本與文字卡片使用 ICU「簡體→繁體」轉換；原文件若有亂碼、缺字或辨識錯誤則不擅自增加故事內容。
