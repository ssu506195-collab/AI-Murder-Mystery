# 紙妻｜免 Token V6.5（GitHub Pages 直接上傳版）

此 ZIP 已包含完整網站，不需要 Cloudflare Worker、Groq API Key、npm 或任何建置步驟。

## 安裝

1. 解壓縮 ZIP。
2. 將**壓縮檔內所有檔案及資料夾**上傳到 GitHub Repository 的根目錄，覆蓋 V6.2 / V6.3 舊檔。
3. GitHub Repository → Settings → Pages：Source 使用 Deploy from a branch，Branch 設 main，Folder 設 /(root)。
4. 瀏覽器按 Ctrl+F5 強制更新快取。
5. 若你要從選角流程重新體驗，請在遊戲內按「重新開始」。

## 本版主要修改

- **首頁**：保留舊版七人群像，簡介改成通用劇本殺玩法介紹。
- **選擇劇本**：《紙妻》卡片顯示民國江南陳宅的劇本簡介、7 人、估計 4–6 小時；不顯示幕次與提示卡張數。
- **選角**：角色卡片替換成七張各自繪製的民國人物肖像。可自行選角或隨機選角。
- **在場人物**：確認選角後先逐一介紹七個角色，再進入分段、逐字打字的序章。
- **對話立繪**：七位角色另附透明背景肖像；孔神婆增加正常與附身兩種肖像；發言者明亮，另一方變暗。
- **背景**：序章與宅院使用江南中式老宅，孔神婆作法使用紅燭婚房，問答不再使用西式書房。
- **操作**：玩家選擇提問後逐字顯示提問，接著自動切換成角色回答；回答顯示完畢需由玩家點「下一步」繼續。
- **延續 V6.2**：角色劇本依幕解鎖、固定追問、抽卡、個人與公開情報分離、推理及結局。

## 注意

- 這是**單人、免 Token、純前端**測試版；角色與真相資料仍存在靜態網站程式中，原始碼可查看，並非安全的多人隱藏資訊架構。
- V6.5 沒有重寫 V6.2 的全部問答樹，也沒有修改原本抽卡配額。
- 人物透明背景使用影像分割，頭髮與暗色服裝邊緣在極亮背景下可能有些微瑕疵。
- 遊玩時間 4–6 小時是參考估計，單人閱讀速度會影響實際時間。

## 主要檔案

- index.html：GitHub Pages 首頁
- app.js：遊戲流程與問答呈現
- style.css：畫面樣式
- data/game-data.js：固定劇本與線索
- data/visual-data.js：劇本卡片與角色圖片對照
- assets/portraits/：九張透明背景肖像（七主角＋孔神婆兩種狀態）
- assets/scene/：首頁群像、陳宅外院、婚房儀式三種主場景
